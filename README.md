AI Lab Assignment 2: Python Collections, Functions and Simple Intelligent Agents

This lab assignment focuses on understanding and implementing Python collections, including lists, tuples, sets, and dictionaries, along with loops, functions, and simple intelligent agents. It demonstrates how these Python concepts can be applied to Artificial Intelligence tasks such as knowledge representation, state tracking, route selection, and decision-making.

The assignment also includes the implementation of rule-based agents and a vacuum cleaner agent to understand how intelligent agents observe their environment and select appropriate actions based on predefined rules. Through practical examples and programming challenges, this lab strengthens Python programming skills and builds a foundation for understanding intelligent agents in Artificial Intelligence.
